# Identity — GitHub Pages build

Live app: https://alpineberry-x.github.io/identity-pages/

This repository holds only the compiled production build of Identity 2.0.1, a local-first app for a short daily check-in, with a Russian interface. It contains no application source code. GitHub Pages serves these files unchanged from the root of the `main` branch.

Identity keeps its records only in the browser where they are entered, in `localStorage`. There is no backend, account, or synchronization between browsers or devices.
